# Data Visualization Internship Task Submission

## Project Overview
This project demonstrates data visualization skills using Python, Pandas, Matplotlib, and Seaborn. 
The analysis is performed on a restaurant tips dataset with 244 transactions.

## Task Objectives
- Transform raw data into visual formats (charts, graphs)
- Create clear, insightful visualizations
- Tell compelling data stories that support decision-making

## Key Insights Discovered
1. Best Day for Tips: Sunday with average tip of $3.26
2. Average Tip Overall: $3.00 (approximately 15% of bill)
3. Most Common Party Size: 2 people (64% of transactions)
4. Gender Difference: Males tip slightly higher ($3.09 vs $2.83)
5. Smoker Analysis: Smokers tip more ($3.11 vs $2.97)

## Technologies Used
- Python 3.x
- Pandas (Data manipulation)
- Matplotlib (Visualization)
- Seaborn (Statistical visualizations)

## Visualization Types Created

- Dashboard (Multiple visualizations combined)
